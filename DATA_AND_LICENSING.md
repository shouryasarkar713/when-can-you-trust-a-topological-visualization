## Third-party data

| Data | Source | Where in this repository |
|---|---|---|
| Daily weather observations, station 72505394728 (NY City Central Park), 2019–2024 | NOAA National Centers for Environmental Information, Global Summary of the Day (GSOD), access directory `https://www.ncei.noaa.gov/data/global-summary-of-the-day/access/<year>/72505394728.csv`; documentation `https://www.ncei.noaa.gov/data/global-summary-of-the-day/doc/readme.txt` | `technical/scikit-tda-trust/extensions/meteorology/data_provenance/raw/gsod_72505394728_<year>.csv` (unmodified downloads, SHA-256 in `provenance.json`) and `processed/` (derived by `scripts/preprocess_weather.py`) |
| Oceanic Niño Index (ONI) table | NOAA Climate Prediction Center, `oni.data` | `.../data_provenance/raw/oni.data` |

The raw files are about 0.5 MB in total and are included unmodified so that the weather analysis can be reproduced from raw
inputs without network access. They remain third-party data: their use is governed by NOAA's own data-access and usage
policies, not by the author of this repository, and the author makes no statement about their licence. If you need to
redistribute them, check NOAA's current terms or re-download them with
`extensions/meteorology/scripts/fetch_gsod.py` (network required; it records fresh hashes in `provenance.json`, which you can
compare with the shipped ones; NOAA may have revised the files since the download recorded there).

The synthetic point clouds (annulus, figure-eight, blob, three blobs) are generated by `src/` from the seeds in `configs/`
and need no external data.

## Third-party software

The code uses ripser, persim, KeplerMapper (`kmapper`), tadasets, scikit-learn, numpy, scipy, matplotlib, networkx, PyYAML,
pytest and, for the verification tools, python-docx, python-pptx and PyMuPDF at the versions pinned in
`technical/scikit-tda-trust/requirements*.txt`. They are installed from PyPI and are not redistributed here; each is
governed by its own licence. The explorer is a self-contained HTML file with its own code and no external scripts.
