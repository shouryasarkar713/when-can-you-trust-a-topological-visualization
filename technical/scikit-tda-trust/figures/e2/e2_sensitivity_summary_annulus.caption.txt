E2 sensitivity summary for annulus (24-cell grid; 12 shown per shape). LEFT: connected-component count per cover parameter cell (networkx). MIDDLE: cyclomatic number E − V + C, the count of independent graph cycles (see caveat). RIGHT: membership-overlap S vs the pre-specified reference cell (REF). S is a custom exploratory overlap indicator (symmetric mean of best membership-Jaccard matches), not a metric and not a canonical Mapper graph similarity; it is greedy, edge-blind, and not normalized for node count, so it must not be used to rank graphs across different cover resolutions. Read it only against the pre-specified reference cell, beside component counts and representative graphs. Mapper graph cycles are not automatically equivalent to true topological loops in the data: the no-loop control produces short noise-scale graph cycles while its H1 diagram correctly shows no dominant class. Cycle length and scale context distinguish loop-like structure from noise. Interpretation rests primarily on the component counts, cycle statistics, and representative panels, not on S alone.
